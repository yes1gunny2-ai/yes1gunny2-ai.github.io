[3] 규칙 위반 저장 시도
  확인: 토큰 없는 추가 요청 거부 (HTTP 401)
  확인: 200자 미만 본문 거부 (HTTP 400): body: 본문은 200~1000자여야 합니다. 현재 5자입니다.
  확인: 확인 전 수치의 공개 저장 거부 (HTTP 400)

[4] 추가 → 저장 → 빌드
  확인: 프로젝트 추가 (HTTP 201, id 9)
  확인: 프로젝트 수 9개
  확인: 다대다 관계 저장 (기술 2건)
  확인: 빌드 결과에 상세 페이지 생성 (/projects/db-proof-test/)

[5] 수정 → 저장 → 빌드
  확인: 프로젝트 수정 (HTTP 200)
  확인: 빌드 결과에 수정 내용 반영

[6] 삭제 → 저장 → 빌드
  확인: 프로젝트 삭제 (HTTP 200)
  확인: 연결된 관계 행 함께 삭제
  확인: 프로젝트 수 8개로 복귀
  확인: 빌드 결과에서 상세 페이지 제거
