뉴스 기사 입장 분석 모델

낮은 성능의 원인을 분석하고 주제 전환을 판단한 기록

KLUE RoBERTa Macro-F1
0.476
평가 조건의 원본 로그는 확인 중
본인 기록
분석 데이터
기사 2,000건
K-News-Stance
원본 대조

기술 설명 514자

한국어 뉴스 기사의 입장을 분석하려던 프로젝트입니다. K-News-Stance 2,000건의 구조를 분석하고, 규칙 기반 엔진과 KLUE RoBERTa 학습 코드, Streamlit 라벨링 도구를 만들었습니다.

KLUE RoBERTa 실험의 Macro-F1은 0.476이었습니다. 저는 이 결과를 모델 조정만의 문제로 보지 않았습니다. 첫째, 입장 라벨은 이슈 단위의 약한 라벨이라 주제나 기사 단위 판단으로 바로 쓸 수 없었습니다. 둘째, 같은 사건의 기사가 분할에 섞이면 평가가 왜곡될 수 있습니다. 셋째, 교수 피드백처럼 입장 판정은 라벨의 객관성과 사회적 신뢰성을 설명해야 합니다.

규칙 기반 방식은 근거 문장을 제시할 수 있었지만 사전과 임계값에 의존했습니다. 이 한계를 근거로 팀은 정답을 더 명확히 정의할 수 있는 주제로 전환했습니다. 성능 수치를 올리지 못한 프로젝트이지만, 낮은 점수에서 데이터와 문제 정의를 점검하고 방향을 판단한 경험으로 정리합니다. 0.476의 원본 평가 로그는 확인 중입니다.

목표

한국어 뉴스 기사의 주제와 입장을 근거와 함께 분석하고, 규칙 기반과 학습 기반을 같은 기준에서 비교합니다.

01문제 정의

뉴스 입장은 정답 자체가 해석에 달려 있습니다. 공개 데이터의 입장 라벨은 이슈 단위이고, 주제 라벨로 그대로 쓸 수 없습니다. 같은 사건의 기사가 학습과 시험에 나뉘면 누수도 생깁니다.

모델을 바꾸기 전에 "라벨이 측정하려는 것을 측정하는가"를 확인해야 했습니다.

02수행 과정

  • K-News-Stance 기사 2,000건의 구조와 이슈 분포를 분석했습니다.
  • 규칙 기반 분석 엔진을 만들어 점수마다 원문 근거를 남겼습니다.
  • Streamlit 라벨링 도구로 사람 라벨을 쌓았습니다.
  • KLUE RoBERTa 학습·평가 코드를 만들어 실험했습니다.

03결과

KLUE RoBERTa 실험의 Macro-F1은 0.476이었습니다(본인 기록). 규칙 기반 분석은 근거를 설명할 수 있었지만 단어 사전과 임계값에 크게 의존했습니다.

교수 피드백에서 라벨의 객관성과 사회적 신뢰성 문제가 제기되었고, 팀은 평가 가능한 범위를 다시 정해 주제를 전환했습니다.

04한계

  • 0.476의 데이터 분할과 라벨 조건을 기록한 원본 로그를 찾지 못했습니다.
  • 약한 라벨이 섞여 낮은 점수의 원인을 모델과 데이터로 분리하지 못했습니다.
  • 입장 분석 결과는 사회적 판단으로 읽힐 위험이 있어, 라벨의 근거를 설명할 수 없으면 신뢰를 주장하기 어렵습니다.

05개선 방향

  • 라벨 정의와 평가자 일치도를 먼저 측정한 뒤 모델을 학습합니다.
  • 이슈 단위로 데이터를 분할해 같은 사건의 누수를 막습니다.
  • 실험마다 분할과 라벨 버전을 함께 저장합니다.

구현·검증 범위

  • 규칙 기반 Topic·Stance 엔진구현
  • Streamlit 라벨링 도구구현
  • KLUE RoBERTa 학습·평가 코드구현
  • Macro-F1 재현 가능한 로그 보존미수행·미확인

배운 점

점수가 낮을 때 모델만 바꾸는 대신 문제 정의부터 다시 볼 수 있어야 한다는 점을 배웠습니다. 계속 진행할지 멈출지를 근거로 판단한 경험입니다.
