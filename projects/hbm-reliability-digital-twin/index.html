HBM Reliability Digital Twin 초기 설계

기술 설명 528자

웨이퍼 결함과 HBM 적층 신뢰성을 연계하려던 5인 캡스톤 초기 구상입니다. WM-811K(전체 811,457장, 라벨 172,950장)를 감사하고 공개 HBM 현장 오류 데이터로 Random Forest를 재현했습니다.

핵심 발견은 평가 조건의 영향입니다. Column 수준 RF의 F1은 시험셋 음성을 표본 추출한 재현에서 0.796이었지만, 표본 추출 없는 CSV 순서 분할에서는 0.183이었습니다. 양성 비율이 8.64%에서 0.85%로 달라지기 때문입니다. 같은 시험 구간에서 XGBoost는 0.281이었으나 여러 시드와 외부 검증이 없어 우월성을 주장하지 않았습니다.

구현과 설계를 구분하면, 데이터 감사·RF/XGBoost 평가·추상 적층 지표·Streamlit 앱은 실행했고, ResNet18은 36장 학습의 동작 확인까지만 수행했습니다. 전체 학습과 Grad-CAM은 실행하지 않았습니다. 물리적 대응 없이 웨이퍼 맵을 HBM 층으로 연결할 수 없다고 판단해 단일 위험도 융합을 제외했고, 이후 팀은 방향을 전환했습니다.

목표

웨이퍼 결함 패턴과 HBM 적층 신뢰성을 연계하는 연구 구상의 타당성을 공개 데이터로 먼저 점검합니다.

01문제 정의

초기 구상은 Wafer Map 분류 결과를 가상 적층으로 이어 HBM 위험도를 예측하는 파이프라인이었습니다. 그러나 WM-811K의 한 픽셀은 웨이퍼 위 die 판정이고 die 내부 TSV나 셀 위치 정보가 없습니다. HBM 현장 오류 데이터와 연결할 라벨도 없습니다.

"두 데이터를 하나의 위험도로 합칠 수 있는가"를 먼저 따져야 했습니다.

02수행 과정

  • WM-811K 전체 무결성과 라벨 분포, 이미지 중복을 감사했습니다.
  • 공개 HBM 현장 오류 데이터(Calchas)로 Random Forest를 재현하고, 표본 추출·분할 방식을 바꿔 다시 평가했습니다.
  • XGBoost를 같은 시험 구간에서 비교했습니다.
  • 웨이퍼 패턴 마스크를 겹치는 추상 적층 지표 S를 정의하고 2·4·6·8층으로 실험했습니다.
  • ResNet18은 2채널 입력 전처리와 소표본 동작 확인까지 진행했습니다.

03결과

기존 기록의 Column RF F1 0.7517은 웨이퍼가 아니라 HBM 현장 오류 데이터의 결과이며, 혼동행렬과 산술은 일치하지만 같은 실행의 재현은 확인하지 못했습니다. 명시적 시드 재현은 0.796이었으나, 시험셋을 표본 추출하지 않은 CSV 순서 분할에서는 0.183으로 떨어졌습니다.

WM-811K 감사에서는 Train과 Test에 같은 원본 맵 해시 3,158개가 있음을 찾았습니다. 추상 적층(8층, 층별 밀도 약 0.08)에서 S는 무작위 0.63, 완전 정렬 7.99였습니다.

04한계

  • ResNet18 전체 학습과 최종 시험은 실행하지 않았습니다. 소표본 동작 확인 값은 성능이 아닙니다.
  • 공개 CSV에는 시간·장비 식별자가 없어 시간 분리나 장비 분리를 검증할 수 없습니다.
  • S는 물리적 고장확률이 아니고 실제 TSV 배치와 무관한 추상 지표입니다.
  • 웨이퍼 입력과 HBM 현장 오류 모델 사이에 과학적 연결 라벨이 없습니다.
  • '디지털 트윈'이라 부를 실측 보정·실시간 동기화가 없습니다.

05개선 방향

  • 팀은 이후 프로젝트 방향을 전환했습니다.
  • 다시 진행한다면 GPU 환경에서 ResNet18 전체 학습과 고정 시험을 수행합니다.
  • 시간·장비 메타데이터를 확보해 그룹 단위 평가를 수행합니다.
  • 두 분기를 합친 단일 위험도 대신 병렬 표시를 유지합니다.

구현·검증 범위

  • WM-811K 전체 무결성·중복 감사실행·결과 확인
  • Calchas 공식 RF 재현과 평가 비교실행·결과 확인
  • XGBoost 비교, SHAP·permutation 분석실행·결과 확인
  • 추상 2/4/6/8층 중첩 지표 실험실행·결과 확인
  • Streamlit 워크벤치 (AppTest 통과)구현
  • ResNet18 소표본 동작 확인 (36장·1 epoch)구현
  • ResNet18 전체 학습과 최종 시험미수행·미확인
  • Grad-CAM (코드만 준비)미수행·미확인
  • 웨이퍼→HBM 가상 적층 위험도 예측설계 단계
  • 실측 보정된 디지털 트윈설계 단계

배운 점

좋아 보이는 지표 하나보다 어떤 분포에서 잰 값인지가 먼저라는 점을 배웠습니다. 평가 조건을 바꾸면 결론이 달라지는 경험은 이후 프로젝트에서 데이터 누수와 라벨 품질을 먼저 점검하는 습관으로 이어졌습니다.
