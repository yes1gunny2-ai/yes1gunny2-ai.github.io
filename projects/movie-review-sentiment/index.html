기술 설명 496자

영화 리뷰를 평가 요소와 방향으로 라벨링하고 영화별로 비교하는 웹 시스템입니다. Next.js와 SQLite로 CSV·XLSX 업로드, 라벨 편집, 대시보드를 구현했고, 백업 기록상 리뷰 5,221건(7편)을 확보한 뒤 6,994건(9편)으로 늘렸습니다. 전처리 후 분석 가능 리뷰는 약 4,991건입니다.

평가의 신뢰성을 위해 시드를 고정한 학습 700·검증 150·시험 150건 분할을 만들고, 중복·유사 리뷰를 포함한 데이터 누수를 검사했습니다. AI가 작성한 라벨 초안은 사람이 검수하기 전 상태이므로 출처와 미검증 상태를 함께 저장해 사람 검토본과 분리했습니다.

KcELECTRA 기반 실험 학습 기록이 있지만 완성 모델이 아닙니다. 학습 라벨이 미검수 AI 초안이고, 개발셋 100건의 엄격 기준 F1 0.700(다수결 기준선 0.103)도 AI 초안과의 일치도일 뿐 사람 정답 기준 성능이 아닙니다. 사람 검수를 끝낸 고정 시험셋에서 다시 평가하는 것이 다음 단계입니다.

목표

영화 리뷰를 평가 요소(스토리·연기·연출·영상·음악·기타)와 방향(긍정·중립·부정)으로 라벨링하고, 영화별로 비교할 수 있는 시스템을 만듭니다.

01문제 정의

리뷰 분석의 정확도는 모델보다 라벨 품질과 평가 분리에 먼저 좌우됩니다. 같은 영화의 중복·유사 리뷰가 학습과 시험에 함께 들어가면 점수가 부풀고, 사람이 검수하지 않은 라벨로 잰 점수는 실제 성능이 아닙니다.

수치를 내기 전에 데이터 흐름부터 검증할 수 있어야 했습니다.

02수행 과정

  • CSV·XLSX 업로드와 리뷰 저장, 라벨 편집, 대시보드를 Next.js와 SQLite로 구현했습니다.
  • 시드를 고정해 학습 700, 검증 150, 시험 150건으로 분할하고 데이터 누수 가능성을 검사했습니다.
  • AI 초안 라벨은 출처와 '미검증' 상태를 함께 저장해 사람 검토본과 분리했습니다.
  • KcELECTRA 기반 실험 학습을 로컬 GPU에서 2회 수행하고 모델 카드에 조건을 기록했습니다.

03결과

2026-10-27 백업 기준 리뷰 5,221건(영화 7편), 이후 영어 리뷰를 더해 2026-10-28 백업 기준 6,994건(9편)입니다. 전처리 후 분석 가능 리뷰는 약 4,991건입니다.

실험 모델은 임시 개발셋 100건에서 AI 초안과의 일치도(엄격 기준 F1)가 0.700으로, 다수결 기준선 0.103보다 높았습니다. 이는 사람 정답 기준 성능이 아닙니다.

04한계

  • 학습 라벨은 사람 검수 전 AI 초안이므로 학습 완료 모델로 볼 수 없습니다.
  • 개발셋은 학습 700건 안에서 잡은 임시 집합이고 라벨도 AI 초안입니다.
  • 사람 정답 기준의 시험은 아직 수행하지 않았습니다.
  • 같은 영화 분포의 결과이며 처음 보는 영화로의 일반화는 평가하지 않았습니다.

05개선 방향

  • 사람 검수를 끝낸 라벨로 고정 시험셋을 만들고 그때 성능을 보고합니다.
  • 처음 보는 영화를 분리한 시험을 별도로 수행합니다.
  • 희소 범주(영상, 음악, 중립)의 표본을 보강합니다.

구현·검증 범위

  • 리뷰 업로드·저장·대시보드구현
  • CSV·XLSX 관리구현
  • 고정 분할과 데이터 누수 검사구현
  • KcELECTRA 실험 학습 2회구현
  • 사람 검수 라벨 기준 시험미수행·미확인
  • 배포용 완성 모델미수행·미확인

배운 점

실험 결과가 나와도 라벨 출처를 먼저 물어야 한다는 점을 배웠습니다. 라벨 출처와 검증 수준을 데이터에 함께 저장하니, 수치가 무엇을 뜻하는지 혼동하지 않고 설명할 수 있었습니다.
