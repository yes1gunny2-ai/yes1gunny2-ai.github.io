MATLAB 기반 레이다 신호처리

레이다 신호 생성, 펄스 압축, 검출 실습

기술 설명 439자

MATLAB으로 레이다 신호를 생성하고 검출하는 신호처리 실습입니다. 입력 신호, 처리 과정, 결과의 세 단계로 흐름을 정리했습니다.

레이다에서 짧은 펄스는 거리 분해능이 좋지만 에너지가 작고, 긴 펄스는 그 반대입니다. 펄스 압축은 일반적으로 변조된 긴 펄스를 보내고 수신단에서 정합 필터를 적용해, 에너지를 유지하면서 좁은 출력 피크를 얻는 방법입니다. 이때 거리 분해능은 펄스 길이보다 신호 대역폭의 영향을 크게 받습니다. 저는 이 개념을 실습의 처리 흐름과 연결해 이해했습니다.

다만 이 항목은 실제 구현 범위를 아직 원본과 대조하지 못했습니다. 코드와 결과 파일을 이 PC에서 찾지 못했기 때문에 사용한 파형, 대역폭, 잡음 조건, 검출 성능 수치는 적지 않았습니다. 위의 설명은 실습의 이론 배경이며, 결과 파일을 확인하면 구체적인 파라미터와 그래프를 추가할 계획입니다.

목표

MATLAB으로 레이다 신호를 생성하고 펄스 압축을 거쳐 표적을 검출하는 처리 흐름을 이해합니다.

01문제 정의

짧은 펄스는 거리 분해능이 좋지만 에너지가 작고, 긴 펄스는 에너지가 크지만 분해능이 떨어집니다. 펄스 압축은 이 상충을 신호처리로 완화하는 방법입니다.

실습의 질문은 입력 신호와 처리 과정이 출력에 어떤 형태로 나타나는지 확인하는 것이었습니다.

02수행 과정

  • 입력: MATLAB에서 레이다 송신·수신 신호를 생성했습니다.
  • 처리: 펄스 압축 관련 처리를 적용했습니다.
  • 출력: 처리 결과를 바탕으로 표적 검출 흐름을 확인했습니다.

03결과

실습에서 입력 신호, 처리 과정, 결과의 흐름을 정리했습니다. 파형 종류, 대역폭, 잡음 조건과 같은 구체적인 파라미터와 결과 수치는 코드와 결과 파일을 확인한 뒤 추가합니다.

04한계

  • 이 PC에서 코드와 결과 파일을 찾지 못해 실제 구현 범위를 원본으로 대조하지 못했습니다.
  • 그래서 수치 결과와 구체 파라미터를 적지 않았습니다.
  • 실제 하드웨어 신호가 아닌 MATLAB 실습입니다.

05개선 방향

  • 코드와 결과 그래프를 찾아 증빙으로 연결합니다.
  • 잡음 조건을 바꾼 검출 결과를 정량적으로 비교합니다.

구현·검증 범위

  • MATLAB 신호 생성과 펄스 압축 실습구현
  • 구체 파라미터·결과 수치 공개미수행·미확인

배운 점

입력과 처리, 출력을 나눠 기록해야 결과를 설명할 수 있다는 점을 다시 확인했습니다. 증빙을 보존하지 않으면 이후에 경험을 검증할 수 없다는 점도 이 항목을 정리하며 느꼈습니다.
