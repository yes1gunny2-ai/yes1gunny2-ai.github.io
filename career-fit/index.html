직무와 경험의 연결

직무에 필요한 역량을 실제 프로젝트 근거와 연결했습니다. 경험이 없는 영역은 그대로 밝힙니다.

1순위 · 반도체 공정기술

변수를 바꿔 결과를 비교하고, 데이터가 어떤 조건에서 나왔는지 해석하는 경험을 기반으로 삼습니다. 공정 현장의 데이터로 수율과 결함을 다루는 일을 배우고 싶습니다.

2순위 · 반도체 장비 CS

증상과 발생 조건, 조치 전후 결과를 구분해 기록하는 습관을 기반으로 삼습니다. 실제 장비 점검은 입사 후 승인된 절차에 따라 배워야 하는 영역입니다.

경험의 범위. 반도체 양산 장비 운용·정비 경력과 기업 인턴 경력은 없습니다. 아래 항목은 학부 프로젝트에서 얻은 기초이며, 현장 역량과 같다고 주장하지 않습니다.

공정기술 관련 역량

  • 소자 특성 이해

    구조와 재료가 전기적 특성에 주는 영향을 설명하는 능력

    • Silvaco TCAD 태양전지 구조 개선텍스처와 후면 구조가 광 흡수와 재결합에 미치는 영향을 조건별로 검토
    • HBM TSV·Micro-bump 구조 분석TSV와 Micro-bump의 저항·정전용량, 열, 응력 고려사항 조사
  • 구조와 성능의 관계 분석

    변수를 바꾸고 결과를 비교해 관계를 찾는 능력

    • Silvaco TCAD 태양전지 구조 개선5개 형상의 효율을 비교하고 변수 동시 변경의 한계를 명시
  • 실험 결과와 데이터 해석

    숫자가 어떤 조건에서 나왔는지 함께 해석하는 능력

    • HBM Reliability Digital Twin 초기 설계F1을 평가 조건과 함께 기록하고, 조건이 함께 달라진 차이의 원인을 단정하지 않음
    • 영화 리뷰 감성 분석 웹 플랫폼AI 초안 일치도와 사람 정답 기준 성능을 구분

장비 CS 관련 역량

  • 오류 분석과 원인 파악

    증상과 추정 원인을 구분하는 능력

    • 뉴스 기사 입장 분석 모델낮은 점수의 원인을 라벨·분할·문제 정의에서 점검
    • 태양광 방향 추적형 스마트 화분무부하와 하중 조건의 증상을 구분하고 미검증 원인을 단정하지 않음
  • 문제 재현과 개선 과정

    단순 조건으로 문제를 재현하고 고친 뒤 다시 확인하는 능력

    • Silvaco TCAD 태양전지 구조 개선실행 오류를 단순 구조에서 재현하며 수정
    • HBM Reliability Digital Twin 초기 설계공개 코드를 재실행하고 코드 결함과 수치 차이를 기록

두 직무 공통 역량

  • 정량적 검증

    기준선과 재현 조건을 두고 결과를 확인하는 능력

    • HBM Reliability Digital Twin 초기 설계공식 함수 직접 실행, 시드 고정 재현, 엄격 분할을 나눠 보고
    • SEMICON ATLAS교차 확인을 통과한 기업만 등록하고 검토 필요 상태를 분리
    • 영화 리뷰 감성 분석 웹 플랫폼다수결 기준선과 비교하고 데이터 누수 검사
  • 공학적 문제 정의

    무엇을 측정해야 하는지 먼저 정하는 능력

    • HBM Reliability Digital Twin 초기 설계웨이퍼 맵과 HBM 층의 물리적 대응이 없음을 확인하고 범위 재정의
    • 뉴스 기사 입장 분석 모델라벨이 측정하려는 대상을 다시 점검
  • 협업과 문제 해결

    역할을 나누고 다른 의견을 조율하는 능력

    • Silvaco TCAD 태양전지 구조 개선담당 범위를 나눠 수행하고 후면 구조 작업은 공동 진행
    • 태양광 방향 추적형 스마트 화분3인 팀에서 코딩, 회로, 조립을 함께 수행
